# Spotify Clone

A responsive frontend recreation of Spotify's web interface.

## Features
- Responsive layout
- Interactive music carousels
- Dynamic carousel navigation
- Search functionality
- Play/pause interactions
- Accessibility improvements
- Hover interactions

## Technologies
- HTML5
- CSS3
- JavaScript
